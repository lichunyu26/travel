## 📝 帖子内容

真心劝所有准备去川西的姐妹！出发前一定要把物资备齐全！别抱着"路上随时能买"的侥幸心理。

### 🎒 物资准备清单

| 物资 | 说明 |
|------|------|
| 🔺 **三合一冲锋衣** | 川西一天过四季，昼夜温差近二十度，可拆卸内胆穿脱自由 |
| 🔺 **亮色裙子** | 多带红色、白色、亮色，稻城亚丁配亮色超上镜。长裙少带，风大走光 |
| 🔺 **鞋袜准备** | 防滑高帮徒步鞋是基础，多带几双旧袜子，徒步走久了可以换 |
| 🔺 **润唇膏护手霜** | 干到嘴巴裂血口，手指起倒刺，一天涂十次都不够 |
| 🔺 **保湿三件套** | 护手霜+保湿面膜+水乳，每天睡前敷1片 |
| 🔺 **少量现金** | 骑马、买藏民家酸奶可能用得上，有些地方信号不好 |
| 🔺 **一次性内裤袜子** | 高原水凉，普通内裤晾两天还是潮的 |
| 🔺 **防晒全家桶** | 墨镜、防晒口罩、高倍数防晒霜（往死里涂） |
| 🔺 **湿厕纸** | 草原山区大多旱厕，湿厕纸干净又方便 |
| 🔺 **小瓶生理盐水** | 风沙大眼睛进东西，别用矿泉水冲，用生理盐水 |
| 🔺 **护发素小样** | 很多藏寨民宿不提供，高原风沙大头发容易打结 |
| 🔺 **保鲜袋（30个起）** | 相机防尘套、装水果、收垃圾、打包脏衣服、装特产 |

### 💡 血泪补充

- **氧气瓶：** 康定药店买25元/瓶，景区门口要60元
- **保温杯必带：** 高原上喝口热水真的舒服很多
- **初到高原头两天别洗头洗澡：** 容易高反
- **离线地图提前下好：** 山里经常没信号
