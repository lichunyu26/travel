## 📅 行程安排

### Day1：上海 → 成都
- **住宿：** 喆啡酒店（西南交大店）
- **美食：** 成都瓜串串（总店）

### Day2：成都 → 四姑娘山（双桥沟）→ 小金
- **住宿：** 小金郦湾酒店
- **美食：** 八六藏餐（赞拉店）

### Day3：小金 → 雅拉雪山观景台 → 墨石公园 → 塔公草原 → 木雅大寺 → 鱼子西 → 新都桥

- **美食：** 藏式火锅（带表演，具体店名不记得，那儿挺多）

### Day4：新都桥 → 红海子 → 成都
- **住宿：** 喆啡酒店（西南交大店）
- **美食：** 抚琴夜市

### Day5：成都 → 上海
- **美食：** 打牙祭（八里小区总店）

## 💡 实用贴士（来自作者评论）

1. **止疼药**要带，可以缓解头疼
2. **晕车药**要带，盘山公路太多，以备不时之需，否则晕车的话也容易诱发高反
3. **巧克力**很需要，可以补充能量，也对高反有些缓解，还可以充饥
4. **帽子、墨镜、冲锋衣**，这三样简直是高原必备，上面紫外线太强
5. **防晒霜**一定要带，其他化妆品可以简化，反正帽子+墨镜已经挡住一大半脸了
6. 可以带个**便携式加湿器**，就那种插在矿泉水瓶的就好，高原实在是太干燥了
7. 带点**厚敷的涂抹面膜**，最好有点油的那种，这样皮肤会没那么干
8. **手机信号**没那么好，一般只有回到酒店和城市，在山里草原的时候信号非常不稳定
