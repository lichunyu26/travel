## 📝 帖子内容

### 🏪 餐厅信息

- **店名：** 扎西德勒•牦牛藏餐
- **位置：** 稻城亚丁·香格里拉镇
- **用餐方式：** 双人套餐（单人用餐，单点不划算）
- **服务评价：** 老板和服务员小姐姐都特别nice！免费续甜茶

### 🍽️ 菜品测评

| 菜品 | 评价 |
|------|------|
| **烤藏香猪排** | 猪排炸的非常干香不油腻，空口吃略微有点咸。配炸土豆外酥里嫩，原味没另外调味 |
| **烤蘑菇** | 意外地不错，调味不咸不淡。蘑菇鲜香和青椒肉沫搭配和谐。单点38元有点小贵 |
| **牦牛肉饼** | 一定要趁热吃！饼皮酥中带韧，口感很好。内馅和蘑菇上的一样 |
| **糌粑** | 造型可爱很有特色，但太太太甜了 |
| **素炒西兰花** | 普通炒素菜，西兰花有点生。水煮后加调料，没料汁的地方淡，有料汁又过咸 |
| **无花果&吉祥三宝酸奶** | 酸奶奶味挺浓但太甜。无花果有点像硬一点的红豆，粉粉的 |
