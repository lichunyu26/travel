## 📍 稻城亚丁长线攻略

### 核心景点
| 景点 | 特色 |
|------|------|
| **牛奶海** | 雪山间的蓝宝石，海拔约4500米 |
| **五色海** | 多彩湖泊，海拔约4600米 |
| **仙乃日** | 雪山三神山之一 |

### 徒步信息
- **路线：** 洛绒牛场 → 牛奶海 → 五色海
- **难度：** 长线，需要较好体力
- **时间：** 全天徒步

### 防高反建议
- 提前准备药物（线上线下都可以买）
- 建议提前服用红景天
- 携带氧气罐
- 头疼吃布洛芬

### 注意事项
- 下山难度可能更大
- 可以自己去，不一定要跟团
- 药品推荐提前准备
