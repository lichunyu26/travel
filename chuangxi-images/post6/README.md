## 💡 实用信息

### 交通方式
- **去程：** 成都坐大巴直达香格里拉镇（亚丁旅游客运站）
- **返程：** 大巴返回成都
- **优点：** 自由行，时间灵活

### 住宿推荐
- **香格里拉镇** — 海拔较低，不容易高反
- **优点：** 去景区方便，住宿选择多

### 游览建议
- 长短线建议分两天游览
- 一天走完会比较累
- 可以根据体力调整行程

### 旅行方式
- 自由行，不需要跟团
- 时间安排更灵活
